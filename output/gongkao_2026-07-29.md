### **第二部分：申论**

**材料1：**
近年来，随着“数字中国”战略的深入推进，我国数字经济规模持续扩大，已成为驱动经济增长的关键力量。数字技术不仅重塑了传统产业的商业模式，更催生了平台经济、共享经济、零工经济等新业态。然而，在快速发展的同时，一些问题也逐渐显现：部分平台企业利用数据、算法等技术优势实施“大数据杀熟”，损害消费者权益；新就业形态劳动者的劳动关系确认难、社保覆盖低、权益保障机制不健全；不同行业、不同区域之间的“数字鸿沟”依然存在，弱势群体在数字化浪潮中面临边缘化风险；数据安全和个人信息泄露事件时有发生，引发社会广泛担忧。

### 📖 解析

### **第一部分：行政职业能力测验（资料分析）参考答案与解析**

#### **1. 答案：A**  
**解析：**  
本题考查基期量计算。2023年数字经济核心产业增加值为127,847亿元，同比增长8.5%。根据公式：基期量 = 现期量 / (1 + 增长率)，代入数据得：  
127,847 ÷ (1 + 8.5%) = 127,847 ÷ 1.085 ≈ 117,831亿元。  
选项A最接近（117,800亿元），因此选A。  
**易错点：** 注意增长率是8.5%，不可误用8.5%直接减除，需准确计算除法。

#### **2. 答案：C**  
**解析：**  
本题考查增速差值比较。四个细分领域增速分别为：  
- 数字产品制造业：6.2%  
- 数字产品服务业：9.8%  
- 数字技术应用业：11.4%  
- 数字要素驱动业：7.8%  
最快为11.4%，最慢为6.2%，差值 = 11.4% - 6.2% = 5.2个百分点。  
因此选C。  
**易错点：** 注意“百分点”表示绝对差值，直接相减即可，无需转换为倍数。

#### **3. 答案：B**  
**解析：**  
本题考查利润率变化（两期比重比较）。利润率 = 利润总额 / 业务收入。  
- 2023年利润率 = 3,857 / 17,083 ≈ 22.57%  
- 2022年利润总额 = 3,857 ÷ (1 + 12.5%) = 3,857 ÷ 1.125 ≈ 3,428.44亿元  
- 2022年业务收入 = 17,083 ÷ (1 + 6.8%) = 17,083 ÷ 1.068 ≈ 15,997.57亿元  
- 2022年利润率 = 3,428.44 / 15,997.57 ≈ 21.43%  
利润率上升了约22.57% - 21.43% = 1.14个百分点，与B选项（上升约1.1个百分点）最接近。  
**技巧：** 也可用两期比重差公式：利润率变化 = (a - b) / (1 + a) × 基期比重，但直接计算更稳妥。

#### **4. 答案：B**  
**解析：**  
逐项分析：  
- **A选项：** 生活服务收入同比下降0.5%，生产服务收入同比增长15.2%，降幅（0.5%）小于增速（15.2%），错误。  
- **B选项：** 数字经济核心产业增加值增速为8.5%，2023年中国GDP实际增速约为5.2%（常识），由于部分增速（8.5%）>整体增速（5.2%），比重上升。
